# Data Pipeline Verification Dashboard

**Backend integration and validation dashboard**

Course project dashboard for **EDS6397-Group01-Incident-Analysis** — Multimodal Emergency Incident Integration Platform.

## Overview

This dashboard validates the backend integration pipeline for the multimodal incident dataset.
All statistics are computed at build time from the source CSV — no mock or placeholder data.

## Severity Rules

Professor Step 4 integration rule (stored in `dataset.csv`):

- `severity_score = Confidence_Score × 10`
- **Low:** 0–3
- **Medium:** 3–7
- **High:** 7–10

Actionable flag (dashboard-derived): False when `Event_Type` is False alarm, N/A, No activity detected, Person walking / present, Unknown, or blank.
